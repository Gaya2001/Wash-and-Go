# Wash and Go Auto Service Center 🚗✨

**"Wash and Go"** is an innovative web-based application designed to streamline the management of customer and admin operations for an auto service center. It offers a smooth, efficient process for users to register, log in, and schedule services such as car washes, oil changes, and repairs. The system also provides an intuitive admin dashboard to manage and oversee the operations effortlessly.

---

## Key Features:

- **User Registration & Login** 📝  
  Customers can easily register and log in to access their profiles, manage service appointments, and track their service history.

- **Admin Dashboard** 🛠️  
  Admin users have full control to manage service records, view customer details, and handle system settings to ensure seamless operations within the service center.

- **Service Scheduling** 📅  
  Customers can book various services in advance, including detailed information such as service types, time slots, and any additional requirements.

- **Session Management** 🔐  
  The system securely stores user data through session management, ensuring safe access to personal accounts and services.

- **CRUD Functionality** 📝  
  Both customers and admins can create, read, update, and delete service records and user information to keep everything up-to-date and well-organized.

- **Error Handling** ⚠️  
  A user-friendly error handling system is implemented directly on the form without any pop-up messages, ensuring a smooth and intuitive user experience.

---

## Technology Stack:

- **Frontend**:  
  - React.js  
  - Tailwind CSS (for a responsive and modern UI)

- **Backend**:  
  - Express.js  
  - MongoDB (for efficient data handling and session management)

- **Authentication**:  
  Secure login system with **role-based access control** to ensure only authorized users can access specific features.

- **Session Management**:  
  Express-session with MongoDB to manage sessions for logged-in users.

- **Database**:  
  MongoDB for storing customer and service-related data.
